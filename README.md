
# AI Hidden Tourist Spot Recommender

## Introduction
This project helps users discover tourist attractions
by entering any city or place.

## Objectives
- Search different locations.
- Find nearby tourist attractions.
- Display results in a simple interface.
- Encourage exploration of new destinations.

## Technologies Used
- Python
- Streamlit
- Requests
- OpenStreetMap

## How to Run
1. Install Python.
2. Run: pip install -r requirements.txt
3. Run: streamlit run app.py
4. Enter a location and click Find Places.

## Future Scope
- Recommend lesser-known attractions.
- Add categories such as nature and history.
- Display locations on an interactive map.
- Add budget-based recommendations.

## Data Source
OpenStreetMap services.

Note: Results depend on available map data.
The current version searches attractions but does not
yet use a trained AI model to identify hidden gems.
