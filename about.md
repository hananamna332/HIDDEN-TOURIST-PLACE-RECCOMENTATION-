# About the Project

## Problem
Travelers may find it difficult to discover attractions
when visiting an unfamiliar place.

## Proposed Solution
This application allows users to enter a location
and find tourist attractions nearby.

## Expected Output
A list of named tourist attractions found near the
location entered by the user.

## Benefits
- Easy to use
- Supports different locations
- Uses online map data
- Can be expanded with AI features

## Limitations
Results depend on the availability of map data and
internet connectivity.
